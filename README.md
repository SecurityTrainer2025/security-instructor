# SECURITY INSTRUCTOR — Full-Stack Training Platform

Production-oriented starter application for **SECURITY INSTRUCTOR | Abdallah Abdelaziz**.

The complete source is being uploaded to this repository, including the bilingual portfolio frontend, Node.js/Express backend, course management foundation, CV, professional gallery, and the two cleaned training presentations.

## Stack
- Frontend: semantic HTML, CSS, vanilla JavaScript.
- Backend: Node.js 20+, Express 5.
- Database: MongoDB + Mongoose.
- Auth: bcrypt + JWT in HTTP-only cookie.
- CSRF: double-submit token.
- Storage: Cloudinary.
- Email: Nodemailer.
- Deployment target: Vercel/Netlify frontend + Render backend + MongoDB Atlas + Cloudinary.

## Status
The repository is prepared for deployment. Production environment variables and hosting services must be connected before the public LMS/API is live.
