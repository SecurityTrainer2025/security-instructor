## النشر والعزل

فُحصت ملفات GitHub Actions في الفرع. يقتصر نشر Pages على `refs/heads/main` عند التشغيل اليدوي أيضًا. سير عمل المرور يبني معاينات أو يرفع ملفات مراجعة أو يتحقق منها. وظيفة إنشاء المعاينات القديمة تدفع أصولًا إلى فرع المرور فقط. فحوص الدخان تستخدم طلبات قراءة. لم تُستخدم قاعدة الإنتاج أو ترسل رسائل بريد، ولم يُحذف أي سجل.

حُفظ العمل في Commit محلي على الفرع التجريبي. لم يُدفع أي تحديث إلى GitHub أو يُشغّل أي نشر عبر Render. لا يبيّن المستودع إعداد الفرع أو النشر التلقائي لخدمة Render في لوحة التحكم، لذلك بقيت تلك الإعدادات غير متحققة.
