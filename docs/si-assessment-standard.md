# SI Assessment Standard for Courses and Workshops

## Default standard for future programs

For new SI courses and workshops, the formative assessment section is placed at the end of the learning content, immediately before the final assessment.

- Present formative assessment questions in assessment slides/blocks.
- Each assessment slide/block contains 8–10 questions.
- Learners complete this assessment before starting the final assessment.
- Keep formative assessment separate from the final assessment; do not treat formative results as the final score.
- Define and document the pass threshold, retry rules, question randomization, and answer-shuffling rules for each program before release.
- Grade answers on the server where the platform supports it; do not expose correct-answer keys to the learner.
- Test the complete learner journey, progress saving/resume, mobile and desktop display, and certificate eligibility before release.

## Scope and compatibility

This is the default for future courses and workshops. Do not automatically migrate, rewrite, or alter the existing five course workflows or their stored data.

## AVS-EMRG-2026 current workshop

The AVS airport workshop currently has its own previously specified design: 15 content slides, each followed by a five-question formative check (15 checks total), then a 30-question final assessment. Keep this workshop-specific design unchanged while finishing and validating the current release candidate. Any change to this AVS-specific structure requires explicit owner approval and corresponding updates to its manifest, workflow, question banks, and tests.

## Release control

This standard is a design rule, not evidence that any course or workshop is approved or ready to launch. Content review, question-bank validation, scoring-boundary tests, randomization, persistence, email, certificate verification, and end-to-end checks remain separate release gates.
