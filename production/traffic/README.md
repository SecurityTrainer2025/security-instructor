# حزمة إنتاج دورة إدارة حركة المرور والتحكم في المركبات في الموقع

تضم الحزمة عشرة دروس و21 مشهدًا. يصف `SCENE_LIST.csv` كل مشهد ويربطه بالنص العربي والترجمة الإنجليزية والصورة والتوقيت التخطيطي. يستخدم `scene-plan.json` المحتوى نفسه لتجميع ملفات MP4. بعد التسجيل، يقيس السكريبت عينات الصوت الفعلية ويكتب التوقيت النهائي في ملفي VTT وJSON لكل درس.

## التشغيل على Windows

1. فك ضغط الحزمة إلى مجلد قابل للكتابة. ثبّت Python 3.10 أو أحدث وFFmpeg يتضمن مرشّح `subtitles` وترميز `libx264`، وأضف مجلد `bin` الخاص بـ FFmpeg إلى `PATH`.
2. انقر مرتين على `START_PRODUCTION.bat`. يفحص الملف المتطلبات والمواد ويعرض خيارين:
   - **R** للتسجيلات المحلية دون خدمة صوت. أنشئ مجلد `narration`. احفظ تسجيلًا عربيًا لكل مشهد باسم مثل `tm1s1-01.wav` أو بالامتداد `.mp3` أو `.m4a`. سجّل النص من عمود `ar` في ملف المشاهد.
   - **E** لتوليد التسجيلات الناقصة عبر Edge TTS بالصوت `ar-EG-ShakirNeural`. يثبّت الملف مكتبة Python المجانية عند الحاجة. يعتمد هذا الخيار على وصول Windows إلى خدمة النطق. استخدم التسجيلات المحلية إذا تعطّل الاتصال أو احتاج النطق إلى تصحيح.
3. تظهر الملفات في `review-output` بعد نجاح التحقق. عند إعادة التشغيل انقل مجلد الناتج أو استخدم `--output` مع مسار جديد. إذا أخفق مشهد، يظهر معرّف الدرس ورقم المشهد في نافذة التشغيل.

لإنتاج درس منفرد من موجه الأوامر:

```bat
START_PRODUCTION.bat --lesson tm5s1 --output review-signals
```

استخدم `--edge-voice ar-EG-ShakirNeural` مع أمر الدرس المنفرد إذا سبق تثبيت المكتبة واخترت الصوت الشبكي. لا يتطلب التجميع نفسه اشتراكًا أو رفع الصور والتسجيلات إلى خدمة مونتاج.

## الصور والمراجعة

الصور الواقعية في الحزمة تمثيلات مولّدة خصيصًا للمشروع، والمخططات تصاميم أصلية خاصة بالدروس. لا تحتوي على صور مخزون طرف ثالث. استُخدم شعار SI من أصل الشعار المضمّن في المشروع، وتظهر عبارة **مادة تدريبية تمثيلية** على الأطر. تعرض مخططات المرور مبادئ فصل المسارات واتخاذ القرار. راجع التطبيق والإشارات وفق مخطط الموقع مع مدرب مؤهل. المواد التمثيلية دعم للنص، وتظل مخرجات الحزمة في مجلد المراجعة.

## إعادة الاستخدام للدورات الأخرى

انسخ المشغّل و`produce.py`، وأنشئ ملف خطة بنفس بنية `scene-plan.json` مع معرف مستقل لكل درس ومصفوفة `scenes`. يحتاج كل مشهد إلى `visual` لمسار الصورة النسبي إلى الخطة و`ar` للنص و`en` للترجمة. استخدم صورًا ومخططات تملك حقوقها، وسمّ التسجيلات وفق معرّف الدرس ورقم المشهد، ثم مرّر الخطة الجديدة:

```bat
START_PRODUCTION.bat --manifest "Other Course\scene-plan.json" --audio-dir "Other Course\narration" --output "Other Course\review-output"
```

يستخدم المحرّك أي عدد من الدروس أو المشاهد دون الاعتماد على معرفات المرور أو قاعدة بيانات المنصة. تُفحص أبعاد الفيديو وترميز H.264 وAAC ومدة مسار الترجمة وفك الترميز قبل إنهاء العمل.
